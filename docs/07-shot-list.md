# 07 — Shot list: photography, video, renderings, logos

Compiled 4 Nov 2026 from every media slot on **Desktop Site v3** and
**Mobile Site v3**. It covers the placeholder briefs, the stand-in images
and the content the outline marks as missing. Nothing here is a new client
fact. Each item is a slot the design already has. Open-question numbers
refer to `CLAUDE.md` §10.

**Every asset needs, with the file:**

- the date taken;
- credit;
- **Photograph / Rendering / Video** flag (Q10);
- a one-line description for alt text;
- confirmation of usage rights.

Captions and dates appear on the page, so a photo without a date can't
fill a dated slot.
